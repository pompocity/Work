# EnteRent — Interactive Prototype

A front-end-only React prototype (Vite + Tailwind) of the EnteRent tenant and landlord apps, using mock data.
It ships three ways:

| Target | How |
|---|---|
| Web (GitHub Pages) | `npm run deploy` → https://pompocity.github.io/Work/ |
| Local web dev | `npm install` then `npm run dev` |
| **iOS app** | Open `ios/App/App.xcodeproj` in Xcode — see below |

---

## Build the iOS app on a Mac

The iOS app is a [Capacitor](https://capacitorjs.com) native shell that loads the bundled web build.
The compiled web files are committed in `ios/App/App/public`, and the only native dependency is a
Swift package Xcode downloads by itself — so **the Mac needs only Xcode. No Node, npm, or CocoaPods.**

### One-time setup
1. Install **Xcode** from the Mac App Store and open it once to accept the license.
2. Open **Xcode → Settings → Accounts** and sign in with your Apple ID (a free account works for
   installing on your own iPhone).

### Build & run
```bash
git clone https://github.com/pompocity/Work.git
open Work/ios/App/App.xcodeproj
```
In Xcode:
1. Wait a few seconds for **"Resolving Package Graph"** to finish (it fetches Capacitor once).
2. Select the **App** target → **Signing & Capabilities** → choose your **Team**.
   If Xcode reports the bundle ID is taken, change `com.enterent.prototype` to something unique,
   e.g. `com.yourname.enterent`.
3. Choose a simulator (e.g. iPhone 16) or your plugged-in iPhone from the device menu at the top.
4. Press **▶ Run** (⌘R).

**Running on a physical iPhone:** the first time, enable **Settings → Privacy & Security → Developer Mode**
on the phone, and after the first install trust your certificate under
**Settings → General → VPN & Device Management**.

**To share with others (TestFlight):** this needs a paid Apple Developer account ($99/yr).
In Xcode choose **Product → Archive**, then **Distribute App → TestFlight & App Store**.

### Notes
- Fonts and photos load from Google's CDN, so the app needs an internet connection.
- Demo data is saved on the device. Use **Unit/Key** (tenant) or **Account** (landlord) →
  *Demo Scenario → Reset all demo data* to start fresh.
- iPhone is locked to portrait; iPad supports all orientations.

## Updating the app after changing the web code

Web changes are made in `src/` on any machine that has Node:

```bash
npm install          # first time only
npm run ios:sync     # builds the web app and copies it into ios/App/App/public
git add -A && git commit -m "..." && git push
```
Then on the Mac: `git pull` and press **▶ Run** in Xcode again.
`npm run deploy` updates the GitHub Pages site separately.
